# EricoMazeGame (No maze or game yet sorry)

Simple Maze Game Built with HGE (maybe to my detriment) 

## How to Build

Assuming you are on Windows and have already ran [this](https://www.microsoft.com/en-us/download/details.aspx?id=6812) to install the  Directx 9 SDK, run `cmake -B build` to generate a Visual Studio Solution in this directory. `cmake -B build -A Win32` is for x86 version of the solution. 

## How to Run

If you've built the game from source the executable will be somewhere in `./bin` depending on what build configuration you chose. 

I am still working on a portable version with all the necessary DLLs.
